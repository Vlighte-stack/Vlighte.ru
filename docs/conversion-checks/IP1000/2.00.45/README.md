# Последняя матрица — 2.00.45

27 октября 2026 года. Установленная на vlighte.ru контрольная точка. IP1000 и те же десять внешних фикстур, все замкнутые цепочки из четырёх преобразований (891 сценарий), без XML-комментариев восстановления между шагами.

Все **79 прежних потерь точности CIE устранены в варианте с ZIP**: 22 цепочки — нативные XYZ/CIE HOG/GDTF, 57 — MA2 ZIP с открытым colorimetry.json. Максимальная разница xyY около 7.1×10⁻¹⁵ на 37 017 точках. Сам MA2 продолжает использовать RGB. Для следующего точного преобразования передавайте весь ZIP, а не один XML. Импорт в реальный HOG PC/MA2 и поведение Color Picker не проверены.

Каждый из трёх прогонов: 0 ошибок преобразования, 228 MATCH и 663 DIFFERENT по прежнему структурному анализу XML. DIFFERENT не равно потере цвета. Во всех прогонах проверены физические шкалы, Default, адресация, разрешение, условия, виртуальный диммер и назначения управления; изменений в этих проверяемых полях не найдено. В отдельном MA2 XML-прогоне остаются 57 строк потери точного CIE, поскольку JSON не передаётся; это ограничение открыто отражено в отчёте.
