# IP1000 Tilt Strobe: GDTF → HOG → GDTF

Версия 2.00.38, режим 44ch Mode. Первый HOG сохранён на диск и повторно открыт как самостоятельный вход второго преобразования. Исходный GDTF отдельно во второй этап не передавался. Проверка выполнена локально кодом контрольной точки GitHub 5fdf3d9; библиотека сайта не изменялась.

## Предел проверки

Сохранность данных в этой цепочке зависит от служебных комментариев, которые наш редактор помещает в HOG. Импорт и повторный экспорт через реальный пульт HOG здесь не выполнялись: если пульт удалит эти комментарии, результат может отличаться. Итоговый description.xml прошёл официальную схему GDTF 1.2 (https://github.com/mvrdevelopment/tools/blob/main/gdtf.xsd). 3D-модели и изображение логотипа/миниатюры не включены в экспорт GDTF текущей версии.
