# Проверки преобразования IP1000 — 2.00.38

Результаты сохранены 26 октября 2026 года. Преобразования выполнены локально кодом контрольной точки [5fdf3d9](https://github.com/Vlighte-stack/Vlighte.ru/commit/5fdf3d9fd80057aed034e0f48055b63736e6461c). Каждый промежуточный файл сохранялся на диск и повторно открывался как вход следующего этапа.

## GDTF → HOG → GDTF

Исходник: Extreme_Stagelights@IP1000_Tilt_Strobe@rev14.gdtf, режим 44ch Mode.

- [Отчёт](IP1000_GDTF-HOG-GDTF_2.00.38/Сравнение.md) и [полные различия JSON](IP1000_GDTF-HOG-GDTF_2.00.38/comparison.json).
- DMXModes совпадает с оригиналом: 44 DMX-адреса, 53 функции, 19 ChannelSet, 8 виртуальных диммеров с учётом повторов.
- Отличия: имена прибора, отсутствие 3D-моделей и миниатюры, служебные комментарии восстановления. Исходный и итоговый description.xml сохранены рядом с промежуточным HOG и итоговым GDTF.

## MA → HOG → GDTF → HOG → MA

Исходник: @strobe1000_light@42ch.xml.

- [Отчёт](IP1000_MA-HOG-GDTF-HOG-MA_2.00.38/Сравнение.md) и [сравнение JSON](IP1000_MA-HOG-GDTF-HOG-MA_2.00.38/comparison.json).
- Итоговый MA2 совпадает с оригиналом по элементам, атрибутам и текстовым значениям XML: 42 DMX, 3 модуля, 13 экземпляров, 1 виртуальный диммер, 42 функции, 67 ChannelSet.
- Все четыре промежуточных/итоговых файла расположены в порядке этапов 01–04. Пользовательские атрибуты GDTF перечислены в отчёте и требуют проверки назначения на пульте.

## Границы проверки

Сравнение игнорирует оформление XML, порядок атрибутов и служебные комментарии. Восстановление исходных определений использует комментарии, записываемые нашим конвертером. Импорт и повторный экспорт через реальные пульты или сторонние программы не выполнялись; удаление комментариев может изменить результат.

Оба итоговых/промежуточных GDTF прошли проверку description.xml по официальной схеме GDTF 1.2 из https://github.com/mvrdevelopment/tools. Проверка XSD не подтверждает поведение всех пультов.

SHA256.json содержит контрольные суммы опубликованных файлов, кроме самого манифеста. Это архив результатов; версия приложения остаётся 2.00.38. Исходные ZIP GDTF с моделями и оригинальный MA2 отдельно в этот архив не добавлены.
