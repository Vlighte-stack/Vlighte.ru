# Vlighte.ru — контрольная точка 2.00.38

Снимок исходников рабочей версии от 25 октября 2026 года. Это исходники приложения, а не полный резервный образ хостинга.

## Изменения после контрольной точки 2.00.33

- Импорт GDTF 1.0–1.2: выбор DMX-режима, ссылки на геометрию, 8/16-битные каналы, диапазоны и виртуальные диммеры.
- Одинаковые модули используют одно определение; их экземпляры и DMX-адреса сохраняются.
- Неиспользуемые каналы принадлежат предыдущему рабочему модулю по DMX; начальные пустые каналы — следующему. В HOG не создаются отдельные типы только из пустых каналов.
- Экспорт GDTF 1.2 из HOG4/MA2/GDTF. В библиотеке три формата, GDTF скачивается отдельно; повторная генерация может добавить недостающий GDTF в существующую запись.
- Выбранный файл сначала сохраняется на ПК, затем отправляется в библиотеку. Отмена и ошибка диска не отправляют запись.

GDTF содержит DMX-профиль без 3D-моделей и изображений. Несколько DMX Break, ModeMaster и DMX Relations при импорте требуют дополнительного сопоставления. Непредставимые диапазоны не экспортируются с молчаливой потерей: приложение показывает ошибку/примечание. Если GDTF сформировать не удалось, HOG4/MA2 остаются доступны, а выбранный экспорт GDTF не сохраняется. Комментарии восстановления следует сохранять для обратного преобразования.

Локальные образцы на 42 и 44 DMX прошли проверку GDTF 1.2 XSD из https://github.com/mvrdevelopment/tools. Это не подтверждает импорт на всех пультах. Закрытые пользовательские образцы в репозиторий не включены.

## Возможности

- Преобразование HOG4 и MA2, сохранение исходных определений в XML для обратного преобразования.
- Выбор формата перед генерацией; сохранение на ПК предшествует фоновой отправке сформированных форматов на сервер. Отмена сохранения не отправляет запись в библиотеку.
- Имена MA-MA, MA-HOG, HOG-MA, HOG-HOG с суффиксом vlighte_ru; проверка повторов в библиотеке.
- Общедоступные просмотр и скачивание HOG/MA/GDTF отдельно; управление, IP и корзина доступны владельцу.
- Удаление, восстановление, окончательное удаление отдельной записи и очистка корзины.
- Флаги стран, единые шрифты, логотип и favicon; вход для редактирования расположен внизу библиотеки.

## Развёртывание на существующем хостинге

Python WSGI, стандартная библиотека Python; для блокировок записи используется Linux fcntl. ROOT определяется расположением app.py.

В каталоге аккаунта /var/www/u1815774/data:

- app.py → fixture-stage/app.py
- public/index.html → www/vlighte.ru/public/index.html и fixture-stage/public/index.html
- library/index.html → fixture-stage/library/index.html
- public/logo-pencil.webp → существующий каталог публичных изображений с сохранением адреса, указанного в HTML.

После замены обновить public/tmp/restart.txt в существующем публичном приложении. Существующие WSGI-обёртки, .htaccess, HTTPS и маршрутизацию сохранить.

Для чистой установки нужны отдельные настройки маршрутизации и закрытые зависимости: private/owner-auth.json, private/strobe.xml, private/known.json и профили, на которые ссылается known.json. Эти существующие файлы не включены в публичный репозиторий. Не заменять их пустыми файлами на рабочем сервере.

Пароли, IP, пользовательские профили, saved-files, корзина, журналы и приватные настройки исключены. Базу геолокации и флаги приложение получает отдельно с проверкой хешей; private/country-assets26.zip не входит в снимок.
