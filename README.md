# Vlighte.ru — контрольная точка 2.00.33

Снимок исходников рабочей версии от 21 октября 2026 года. Это исходники приложения, а не полный резервный образ хостинга.

## Возможности

- Преобразование HOG4 и MA2, сохранение исходных определений в XML для обратного преобразования.
- Выбор формата перед генерацией; сохранение на ПК предшествует фоновой отправке обоих форматов на сервер. Отмена сохранения не отправляет запись в библиотеку.
- Имена MA-MA, MA-HOG, HOG-MA, HOG-HOG с суффиксом vlighte_ru; проверка повторов в библиотеке.
- Общедоступные просмотр и скачивание HOG/MA отдельно; управление, IP и корзина доступны владельцу.
- Удаление, восстановление, окончательное удаление отдельной записи и очистка корзины.
- Флаги стран, единые шрифты, логотип и favicon; вход для редактирования расположен внизу библиотеки.

## Развёртывание на существующем хостинге

Python WSGI, стандартная библиотека Python; для блокировок записи используется Linux fcntl. ROOT определяется расположением app.py.

В каталоге аккаунта /var/www/u1815774/data:

- app.py → fixture-stage/app.py
- public/index.html → www/vlighte.ru/public/index.html и fixture-stage/public/index.html
- library/index.html → fixture-stage/library/index.html
- public/logo-pencil.webp → существующий каталог публичных изображений с сохранением адреса, указанного в HTML.

После замены обновить public/tmp/restart.txt в существующем публичном приложении. Существующие WSGI-обёртки, .htaccess, HTTPS и маршрутизацию сохранить.

Для чистой установки нужны отдельные настройки маршрутизации и закрытые зависимости: private/owner-auth.json, private/strobe.xml, private/known.json и профили, на которые ссылается known.json. Эти существующие файлы не включены в публичный репозиторий. Не заменять их пустыми файлами на рабочем сервере.

Пароли, IP, пользовательские профили, saved-files, корзина, журналы и приватные настройки исключены. Базу геолокации и флаги приложение получает отдельно с проверкой хешей; private/country-assets26.zip не входит в снимок.
