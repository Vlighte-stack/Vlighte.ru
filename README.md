# vlighte.ru — Compound Fixture Editor Pro

Рабочая версия **2.00.18**, подтверждена владельцем 20 октября 2026 года.

## Возможности

- Загрузка HOG4 XML и MA2 XML, редактирование составной фикстуры.
- В выходном XML общий `CompoundTypes` расположен непосредственно в `Library`, после блоков `Manufacturer`.
- Нажатие генерации открывает окно сохранения на ПК через File System Access API. После успешной записи точная копия результата и исходник отправляются в библиотеку.
- Отмена окна или ошибка записи не добавляет пару в библиотеку.
- В браузерах без File System Access API используется обычное скачивание с отдельным подтверждением сохранения перед отправкой.
- Публичный просмотр и скачивание библиотеки; удаление в корзину и восстановление — после входа владельца.

## Состав

- `app.py` — WSGI-приложение и генератор.
- `public/index.html` — интерфейс редактора.
- `library/index.html` — интерфейс библиотеки.
- `VERSION` — номер зафиксированной версии.

Это сохранённые исходники рабочей версии, а не полная копия хостинга. Личные пароли, библиотека XML и корзина в репозиторий не включены.

## Размещение на существующем хостинге

Пути указаны относительно `/var/www/u1815774/data`:

| Файл репозитория | Путь на хостинге |
| --- | --- |
| `app.py` | `fixture-stage/app.py` |
| `public/index.html` | `www/vlighte.ru/public/index.html` и `fixture-stage/public/index.html` |
| `library/index.html` | `fixture-stage/library/index.html` |

Существующие `private/owner-auth.json`, XML-шаблон `private/strobe.xml`, изображения, WSGI-обёртки, `.htaccess`, сохранённые XML и настройки HTTPS необходимо сохранить. Они требуются для работы и отсутствуют в этом снимке. Для новой установки их нужно подготовить отдельно.

После замены исходников обновить `www/vlighte.ru/public/tmp/restart.txt`, затем проверить сайт и генерацию. Перед восстановлением сохранить текущую копию файлов хостинга.

## Проверки версии

Сравнение XML с предоставленным владельцем верным образцом подтвердило структуру и сохранение 42 каналов. Проверены порядок локального сохранения/архивации и запрет управления библиотекой без входа владельца. Владелец подтвердил работу в Chrome, Edge и Brave (на другом компьютере после включения File System Access API). Все браузеры не тестировались; импорт в физическую консоль отдельно не проверялся.

Версия 2.00.18 считается базовой рабочей. Следующие изменения должны получать новый номер версии.
